# Interactive Explainers

Two versions of the same story at different levels of abstraction:

- **[index.html](index.html)** — For readers with some math background (3Blue1Brown level). Interactive visualizations of tensor algebra, rank decomposition, and the AD parallel.

- **[eli5.html](eli5.html)** — For anyone curious about AI (zero math). Uses analogies: "torn notebook" for monoids, "flashlights on a heatmap" for attention heads.

Both are self-contained HTML files with no external dependencies.
